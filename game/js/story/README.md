# Historia (rol: Historia)

- `missions/<id>.json`: una misión por archivo. El id se referencia desde `data/planets/<planeta>.json` → `missions`.
- Textos, diálogos y guiones en español. Nada de marcas ni logos de NASA ("Coalición Espacial NASA" debe cambiarse).
- Las cinemáticas existentes están en `js/cinematic/` y las voces en `assets/audio-es/` (también de este rol).
